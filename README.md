# Say Cheese!
## 휴먼폴플랫+폴가이즈 퍼즐 점프맵

물리 기반 이동과 점프를 중심으로 한 3D 캐주얼 액션 플랫폼 게임
장애물을 극복하며 최단 시간으로 스테이지를 완주하는 것을 목표로 합니다.

## 📌 Overview

장르 : 3D 플랫폼 / 물리 기반 캐주얼 액션

레퍼런스 : Fall Guys

개발 인원 : 1인 개발

### 📅 Development Period
2025.10.23 ~ 2025.11.06

## ✨ Features
🏃 물리 기반 캐릭터 이동 및 점프 시스템

⏱️ 스테이지 완주 시간 측정 시스템

💥 추락 횟수 카운트 기능

🧩 장애물 패턴 기반 레벨 디자인

🚩 체크포인트 시스템


## 🛠️ Responsibilities

### 🎮 Game Design
스테이지 구조 설계
시간 기록 시스템 기획

### 💻 Development
플레이어 이동 및 점프 시스템 구현
장애물 및 상호작용 로직 구현
체크포인트 시스템 개발

### 🎨 UI
타이머 UI 제작
