# Say Cheese!
## 휴먼폴플랫+폴가이즈 퍼즐 점프맵

물리 기반 이동과 점프를 중심으로 한 3D 캐주얼 액션 플랫폼 게임
장애물을 극복하며 최단 시간으로 스테이지를 완주하는 것을 목표로 합니다.

## 🚧 Troubleshooting
### 🧥 스켈레탈 메시 회전 불일치 문제 (의상 장착 오류)
❗ 문제

캐릭터에 의상 스켈레탈 메시를 추가했을 때
캐릭터는 정상적으로 서 있지만 의상은 바닥에 90도로 눕는 현상이 발생

🔍 원인 분석

캐릭터 메시와 의상 메시의 기준 좌표계 및 초기 회전값이 서로 달라
동일한 스켈레톤을 사용하더라도 월드 기준에서 정렬이 맞지 않는 문제 발생

🛠 해결 방법

의상 스켈레탈 메시의 Rotation 값을 -90도 보정하여
캐릭터 메시의 기준 축과 일치하도록 수정

✅ 결과

캐릭터와 의상이 동일한 방향으로 정렬되며
자연스럽게 장착되도록 개선


### 🤿 다이빙 애니메이션 루트모션 문제
❗ 문제

다이빙 애니메이션 실행 시
캐릭터가 이동 후 원위치로 돌아오는 현상 발생

🔍 원인 분석

엔진 내 Root Motion 설정을 시도했으나
애니메이션에 Root Bone이 없어 Root Motion 적용이 불가능

🛠 해결 방법

Blender를 활용하여 애니메이션의 이동값을 제거하고
→ 재생 시간 동안 캐릭터를 전방으로 직접 이동하도록 구현

✅ 결과

애니메이션과 이동 로직이 분리되어
의도한 방향으로 자연스럽게 다이빙 동작이 구현됨
